# 📊 Web Traffic Analytics Dashboard

## Project Overview
An interactive dashboard developed to analyze website traffic, visitor behaviour, traffic sources and registration performance.

## Objectives
- Analyze total website sessions.
- Identify the most effective traffic sources.
- Understand visitor device preferences.
- Monitor registration and bounce rates.
- Analyze monthly website traffic trends.
- Evaluate landing page performance.

## Technologies Used
- Python
- Pandas
- Streamlit
- Plotly
- Jupyter Notebook

## Dashboard Features
- Interactive traffic source filters.
- Device category analysis.
- Key Performance Indicators (KPIs).
- Monthly traffic visualization.
- Registration conversion funnel.
- Landing page performance analysis.

## Project Files
- `app.py` – Streamlit dashboard application.
- `web_traffic_analytics_v2.csv` – Dataset.
- `requirements.txt` – Required Python libraries.

## Key Results
- Total Sessions: 900
- Registrations: 166
- Registration Rate: 18.44%
- Bounce Rate: 4.89%
- Average Session Duration: 243.49 seconds

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the dashboard:

```bash
streamlit run app.py
```
