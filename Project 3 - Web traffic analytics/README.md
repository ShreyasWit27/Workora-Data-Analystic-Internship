# 📊 Web Traffic Analytics Dashboard

## 📌 Project Overview

The Web Traffic Analytics Dashboard is a data analytics project developed as part of the **Workora Data Analyst Internship**.

The main objective of this project is to analyze website traffic, understand visitor behavior, measure registration performance, and identify important trends using Python and data visualization.

An interactive dashboard was developed using Streamlit to present the analysis in an easy-to-understand format.

## 🎯 Project Objectives

- Analyze total website sessions.
- Calculate bounce rate and average session duration.
- Measure registration and conversion rates.
- Identify the best-performing traffic sources.
- Analyze traffic based on device categories.
- Understand landing page performance.
- Track monthly website traffic trends.

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Plotly
- Jupyter Notebook
- GitHub

## 📈 Key Performance Indicators

| Metric | Result |
|---|---:|
| Total Sessions | 900 |
| Total Registrations | 166 |
| Registration Rate | 18.44% |
| Bounce Rate | 4.89% |
| Average Session Duration | 243.49 seconds |
| Average Page Views | 3.45 |

## 📊 Dashboard Features

## ▶️ Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/ShreyasWit27/Workora-Data-Analystic-Internship.git
```

### 2. Navigate to the project folder

```bash
cd "Workora-Data-Analystic-Internship/Project 3 - Web traffic analytics"
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit application

```bash
streamlit run app.py
```

## 💡 Key Insights

- The website received 900 sessions in the analyzed dataset.
- Google Organic generated the highest traffic volume.
- Instagram and Email showed comparatively strong registration rates.
- Mobile devices contributed the largest share of website traffic.
- The overall registration rate was 18.44%.
